# HedgeBot Mobile

Production-oriented Expo + TypeScript starter for HedgeBot, an AI-first field service operating system for landscaping and outdoor service businesses.

## Included foundations

- Expo Router tab navigation (Dashboard, Leads, Schedule, Crews, AI, Customers, Marketing, Settings)
- Dark-first neon visual system with reusable theme tokens
- Zustand app session + role state
- React Query client setup
- Offline-ready repository abstraction
- Multi-tenant Supabase SQL schema with RLS starter policies
- Edge function contracts documented for Twilio/OpenAI/Stripe workflows

## Quick start

```bash
cd hedgebot-mobile
npm install
npm run dev
```
